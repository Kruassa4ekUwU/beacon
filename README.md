# Бекон

P2P-передача файлов между устройствами (аналог AirDrop/Shareit/KDE Connect),
собирается в Windows .exe и Android .apk через GitHub Actions.

## Как собрать

1. Создай новый **пустой** репозиторий на GitHub (без README/лицензии).
2. В папке этого проекта на своём компьютере:
   ```
   git init
   git add .
   git commit -m "beacon app"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_ЮЗЕРНЕЙМ/НАЗВАНИЕ_РЕПО.git
   git push -u origin main
   ```
3. Открой вкладку **Actions** в репозитории на GitHub — сборка запустится автоматически (5–10 минут).
4. Когда сборка (галочка зелёная) закончится, открой её и внизу страницы в разделе
   **Artifacts** будут два файла:
   - `Bacon-windows-exe` — распакуй zip, внутри `Бекон*.exe`
   - `Bacon-android-apk` — распакуй zip, внутри `app-debug.apk`

## Установка

- **Windows**: просто запусти `Бекон.exe` (portable, установка не нужна).
- **Android**: перекинь `app-debug.apk` на телефон и открой —
  Android спросит разрешение на установку из неизвестного источника, разреши.
  Это debug-сборка (не подписана для Google Play), но ставится и работает нормально.

## Новое: отправка установленных приложений (как в SHAREit)

На вкладке **«Приложения»** (только в Android-версии) можно посмотреть список
установленных приложений и отправить apk любого из них на другое устройство —
без необходимости искать файл apk вручную.

Пара нюансов:
- Требует разрешение `QUERY_ALL_PACKAGES` — Android покажет это как обычное
  разрешение при установке, ничего дополнительно нажимать не нужно.
- Для очень больших приложений (сотни МБ) чтение apk целиком в память может
  быть медленным — это ограничение простой реализации, для обычных приложений
  проблем не будет.
- Функция работает только в apk-сборке, в .exe и в браузере вкладка покажет
  сообщение, что доступно только на Android.

## Как пользоваться

1. Открой Бекон на обоих устройствах.
2. На одном — покажется 4-значный код.
3. На другом — вкладка «Подключиться», ввести код.
4. После соединения — вкладка «Передать», выбрать файлы.

Передача идёт напрямую между устройствами (WebRTC), файлы не проходят через
сторонний сервер — только служебный сигнал соединения через публичный брокер PeerJS.
Работает и в одной Wi-Fi сети, и через интернет.
